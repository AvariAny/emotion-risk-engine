# Emotion Risk Engine

AI-powered emotional risk assessment engine built with DistilBERT and Hugging Face Transformers.

The project analyzes text and classifies it into four emotional risk levels.

## Features

- NLP-based emotional analysis
- DistilBERT fine-tuning
- Four-level risk classification
- Interactive prediction script
- Modular architecture
- Ready for REST API integration

## Risk Levels

| Label | Meaning |
|-------|----------|
| 0 | No Risk |
| 1 | Low Risk |
| 2 | High Risk |
| 3 | Critical Risk |
